# Novicap

> Novicap is a Spanish working-capital / supply-chain-finance fintech. Its API lets partners submit suppliers and invoices, create payment instructions and adjustments across two products — Dynamic Discounting and Confirming (reverse factoring / Confirming Standard). Backed by Partech and Techstars.

## API
- Base URL: https://api.novicap.com/v1
- Auth: API key as `Authorization: Bearer {api_key}` (or `api_key` in the JSON body); OAuth 2.0 on request. A `product_id` is required on every request.
- Format: JSON request and response bodies.
- Versioning: URI path (`/v1`).

## Products & operations
- Dynamic Discounting: add/retrieve suppliers; add/retrieve/delete invoices; create/retrieve payment instructions; create/retrieve/delete payment adjustments.
- Confirming Standard: add/retrieve/delete invoices; retrieve payment instructions.
